# Security Policy

Do not report vulnerabilities in public issues. Use GitHub **Private Vulnerability Reporting** for this repository.

Include the affected version, reproduction steps, impact, and whether the issue affects repository file access, design import/export, local API boundaries, or the Forge provider protocol.

For vulnerabilities in Forge core rather than Forge Design, report them in the [Forge repository](https://github.com/moretea-labs/forge/security).
